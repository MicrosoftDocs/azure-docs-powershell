# Az.KeyVault Module
## Description
Key Vault secret and certificate lifecycle commands for Azclips

## Az.KeyVault Cmdlets
### [Add-AzKeyVaultCertificate](Add-AzKeyVaultCertificate.md)
Create a certificate version from an explicit certificate policy.

### [Export-AzKeyVaultCertificate](Export-AzKeyVaultCertificate.md)
Download a public X509 certificate as PEM or DER.

### [Get-AzKeyVaultCertificate](Get-AzKeyVaultCertificate.md)
Get public certificate information or enumerate certificate metadata.

### [Get-AzKeyVaultSecret](Get-AzKeyVaultSecret.md)
Get secret metadata, list secrets or versions, or explicitly retrieve a plaintext value.

### [Import-AzKeyVaultCertificate](Import-AzKeyVaultCertificate.md)
Import a PFX or PEM certificate containing a private key.

### [Remove-AzKeyVaultCertificate](Remove-AzKeyVaultCertificate.md)
Soft-delete all versions of a certificate after confirmation.

### [Remove-AzKeyVaultSecret](Remove-AzKeyVaultSecret.md)
Delete all versions of a secret without purging it.

### [Set-AzKeyVaultSecret](Set-AzKeyVaultSecret.md)
Set a secret or create a new version using SecureString input.

### [Undo-AzKeyVaultCertificateRemoval](Undo-AzKeyVaultCertificateRemoval.md)
Recover a soft-deleted certificate and its versions.

### [Undo-AzKeyVaultSecretRemoval](Undo-AzKeyVaultSecretRemoval.md)
Recover a soft-deleted secret and its versions.

### [Update-AzKeyVaultCertificate](Update-AzKeyVaultCertificate.md)
Update supplied certificate attributes, tags or issuance policy.

### [Update-AzKeyVaultSecret](Update-AzKeyVaultSecret.md)
Update secret attributes without changing its value.
