# Set-AzKeyVaultSecret

## SYNOPSIS

Set a secret or create a new version using SecureString input.

## SYNTAX

### __AllParameterSets

```
Set-AzKeyVaultSecret -SecretValue <securestring> -Name <string> [-Enabled <bool>]
 [-Expires <DateTimeOffset>] [-NotBefore <DateTimeOffset>] [-ContentType <string>]
 [-Tag <hashtable>] [-VaultName <string>] [-VaultUrl <string>] [-Profile <string>] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Set a secret in an existing Azure public-cloud vault. An existing name creates a new version. Requires secrets/set permission. Accepts SecureString input and returns metadata without the value. Use either VaultName or VaultUrl. Supports WhatIf and Confirm.

## EXAMPLES

### Example 1

Read a value without placing a plaintext literal in shell history, then set the secret.

```powershell
$value = $Host.UI.ReadLineAsSecureString()
Set-AzKeyVaultSecret -VaultName myvault -Name app-password -SecretValue $value
$value.Dispose()
```

This command does not create a vault. SecureString avoids displaying the input, but the value must exist briefly as plaintext in memory to send the HTTPS request.
