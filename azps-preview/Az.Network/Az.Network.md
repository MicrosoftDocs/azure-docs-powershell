# Az.Network Module
## Description
Azure PowerShell - Network

## Az.Network Cmdlets
### [Get-AzNetworkInterface](Get-AzNetworkInterface.md)
Get a network interface, or list the network interfaces in a resource group or subscription.

### [Get-AzNetworkSecurityGroup](Get-AzNetworkSecurityGroup.md)
Get a network security group, or list the network security groups in a resource group or subscription.

### [Get-AzPublicIpAddress](Get-AzPublicIpAddress.md)
Get a public IP address, or list the public IP addresses in a resource group or subscription.

### [Get-AzVirtualNetwork](Get-AzVirtualNetwork.md)
Get one or more virtual networks.

### [New-AzNetworkInterface](New-AzNetworkInterface.md)
Create a network interface.

### [New-AzNetworkSecurityGroup](New-AzNetworkSecurityGroup.md)
Create a network security group.

### [New-AzPublicIpAddress](New-AzPublicIpAddress.md)
Create a public IP address.

### [New-AzVirtualNetwork](New-AzVirtualNetwork.md)
Create a virtual network.

### [New-AzVirtualNetworkSubnetConfig](New-AzVirtualNetworkSubnetConfig.md)
Create an in-memory virtual network subnet configuration.

### [Remove-AzNetworkInterface](Remove-AzNetworkInterface.md)
Delete a network interface.

### [Remove-AzNetworkSecurityGroup](Remove-AzNetworkSecurityGroup.md)
Delete a network security group.

### [Remove-AzPublicIpAddress](Remove-AzPublicIpAddress.md)
Delete a public IP address.

### [Remove-AzVirtualNetwork](Remove-AzVirtualNetwork.md)
Delete a virtual network.
