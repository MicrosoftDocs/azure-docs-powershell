# New-AzVirtualNetworkSubnetConfig

## SYNOPSIS

Create an in-memory virtual network subnet configuration.

## SYNTAX

### __AllParameterSets

```
New-AzVirtualNetworkSubnetConfig -Name <string> [-AddressPrefix <string[]>]
 [-NetworkSecurityGroupId <string>] [-RouteTableId <string>] [-NatGatewayId <string>]
 [-ServiceEndpoint <string[]>] [-ServiceEndpointPolicy <string[]>] [-DelegatedService <string[]>]
 [-IpamPoolPrefixAllocation <string[]>] [-PrivateEndpointNetworkPoliciesFlag <string>]
 [-PrivateLinkServiceNetworkPoliciesFlag <string>] [-DefaultOutboundAccess <bool>]
 [-Profile <string>] [<CommonParameters>]
```

## ALIASES

None.

## DESCRIPTION

Creates a subnet configuration object without calling Azure.

## EXAMPLES

### Example 1

Create a delegated subnet configuration with a service endpoint.

```powershell
New-AzVirtualNetworkSubnetConfig -Name web -AddressPrefix 10.0.1.0/24 -ServiceEndpoint Microsoft.Storage -DelegatedService Microsoft.Web/serverFarms
```
