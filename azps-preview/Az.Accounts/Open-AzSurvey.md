# Open-AzSurvey

## SYNOPSIS

Opens the feedback form in the default System Browser to provide feedback about Azure PowerShell.

## SYNTAX

### __AllParameterSets

```
Open-AzSurvey [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Opens the feedback form in the default System Browser to provide feedback about Azure PowerShell.

## EXAMPLES
