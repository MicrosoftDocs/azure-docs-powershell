# New-AzStorageShare

## SYNOPSIS

Creates a file share.

## SYNTAX

### Default (Default)

```
New-AzStorageShare [-Url <string>] [-StorageAccountName <string>] [-ShareName <string>]
 [-StorageAccountKey <string>] [-SasToken <string>] [-Metadata <string[]>] [-Quota <int>]
 [-AccessTier <string>] [-EnabledProtocols <string>] [-RootSquash <string>] [-Timeout <int>]
 [-ClientRequestId <string>] [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Creates a file share in a storage account. Use -Quota to set the maximum share size in GiB, and -AccessTier to choose the share's access tier. Authenticate with -StorageAccountName and -StorageAccountKey, or with -SasToken. Alternatively, pass the full resource URL with -Url.

## EXAMPLES

### Example 1: Create a file share

```powershell
New-AzStorageShare -StorageAccountName mystorageaccount -StorageAccountKey $env:AZURE_STORAGE_KEY -ShareName myshare
```

### Example 2: Create a file share with a 100 GiB quota

```powershell
New-AzStorageShare -StorageAccountName mystorageaccount -StorageAccountKey $env:AZURE_STORAGE_KEY -ShareName myshare -Quota 100
```
