# Update-AzStorageShare

## SYNOPSIS

Updates the properties of a file share.

## SYNTAX

### Default (Default)

```
Update-AzStorageShare [-Url <string>] [-StorageAccountName <string>] [-ShareName <string>]
 [-StorageAccountKey <string>] [-SasToken <string>] [-Quota <int>] [-AccessTier <string>]
 [-RootSquash <string>] [-LeaseId <string>] [-Timeout <int>] [-ClientRequestId <string>]
 [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Updates the quota, access tier or root squash setting of a file share. Authenticate with -StorageAccountName and -StorageAccountKey, or with -SasToken. Alternatively, pass the full resource URL with -Url.

## EXAMPLES

### Example 1: Set the quota of a file share

```powershell
Update-AzStorageShare -StorageAccountName mystorageaccount -StorageAccountKey $env:AZURE_STORAGE_KEY -ShareName myshare -Quota 200
```
