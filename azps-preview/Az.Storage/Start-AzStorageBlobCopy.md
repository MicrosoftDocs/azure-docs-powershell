# Start-AzStorageBlobCopy

## SYNOPSIS

Starts an asynchronous copy of a source URL into a blob.

## SYNTAX

### Default (Default)

```
Start-AzStorageBlobCopy -SourceUrl <string> [-Url <string>] [-StorageAccountName <string>]
 [-StorageAccountKey <string>] [-SasToken <string>] [-ContainerName <string>] [-BlobName <string>]
 [-Metadata <string[]>] [-Tags <string[]>] [-Tier <string>] [-RehydratePriority <string>]
 [-LeaseId <string>] [-SourceIfModifiedSince <string>] [-SourceIfUnmodifiedSince <string>]
 [-SourceIfMatch <string>] [-SourceIfNoneMatch <string>] [-SourceIfTags <string>]
 [-IfModifiedSince <string>] [-IfUnmodifiedSince <string>] [-IfMatch <string>]
 [-IfNoneMatch <string>] [-IfTags <string>] [-Timeout <int>] [-ClientRequestId <string>]
 [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Starts a server-side copy from a source URL into a destination blob. The source can be another blob or any publicly readable URL. The cmdlet returns once the copy is scheduled; check its status with Get-AzStorageBlob. Authenticate with -StorageAccountName and -StorageAccountKey, or with -SasToken. Alternatively, pass the full resource URL with -Url.

## EXAMPLES

### Example 1: Copy a public URL into a blob

```powershell
Start-AzStorageBlobCopy -StorageAccountName mystorageaccount -StorageAccountKey $env:AZURE_STORAGE_KEY -ContainerName mycontainer -BlobName copied.md -SourceUrl https://raw.githubusercontent.com/Azure/azure-rest-api-specs/refs/heads/main/specification/storage/data-plane/BlobStorage/readme.md
```

### Example 2: Copy a blob within the account

```powershell
Start-AzStorageBlobCopy -StorageAccountName mystorageaccount -StorageAccountKey $env:AZURE_STORAGE_KEY -ContainerName backup -BlobName myblob.txt -SourceUrl https://mystorageaccount.blob.core.windows.net/mycontainer/myblob.txt
```
