# Az.Storage Module
## Description
AzClips - Storage

## Az.Storage Cmdlets
### [Copy-AzStorageBlob](Copy-AzStorageBlob.md)
Creates a block blob from the content of a source URL.

### [Get-AzStorageAccount](Get-AzStorageAccount.md)
Get one or more Azure Storage accounts.

### [Get-AzStorageBlob](Get-AzStorageBlob.md)
Lists the blobs in a container, or gets the properties of a blob.

### [Get-AzStorageBlobContent](Get-AzStorageBlobContent.md)
Downloads a blob to a local file.

### [Get-AzStorageDirectory](Get-AzStorageDirectory.md)
Gets the properties of a directory.

### [Get-AzStorageFile](Get-AzStorageFile.md)
Lists the files and directories in a file share, or gets the properties of a file.

### [Get-AzStorageFileContent](Get-AzStorageFileContent.md)
Downloads a file from a file share to a local path.

### [Get-AzStorageShare](Get-AzStorageShare.md)
Lists the file shares in a storage account, or gets the properties of a share.

### [New-AzStorageAccount](New-AzStorageAccount.md)
Create an Azure Storage account.

### [New-AzStorageContainer](New-AzStorageContainer.md)
Creates a blob container.

### [New-AzStorageDirectory](New-AzStorageDirectory.md)
Creates a directory in a file share.

### [New-AzStorageFile](New-AzStorageFile.md)
Creates an empty file in a file share.

### [New-AzStorageShare](New-AzStorageShare.md)
Creates a file share.

### [Remove-AzStorageAccount](Remove-AzStorageAccount.md)
Remove an Azure Storage account.

### [Remove-AzStorageBlob](Remove-AzStorageBlob.md)
Deletes a blob.

### [Remove-AzStorageContainer](Remove-AzStorageContainer.md)
Deletes a blob container.

### [Remove-AzStorageDirectory](Remove-AzStorageDirectory.md)
Deletes an empty directory.

### [Remove-AzStorageFile](Remove-AzStorageFile.md)
Deletes a file.

### [Remove-AzStorageShare](Remove-AzStorageShare.md)
Deletes a file share.

### [Set-AzStorageBlobContent](Set-AzStorageBlobContent.md)
Uploads a local file as a block blob.

### [Set-AzStorageFileContent](Set-AzStorageFileContent.md)
Uploads a local file to a file share.

### [Start-AzStorageBlobCopy](Start-AzStorageBlobCopy.md)
Starts an asynchronous copy of a source URL into a blob.

### [Start-AzStorageFileCopy](Start-AzStorageFileCopy.md)
Starts an asynchronous copy into a file.

### [Update-AzStorageShare](Update-AzStorageShare.md)
Updates the properties of a file share.
