# Set-AzStorageFileContent

## SYNOPSIS

Uploads a local file to a file share.

## SYNTAX

### Default (Default)

```
Set-AzStorageFileContent [-Url <string>] [-StorageAccountName <string>] [-ShareName <string>]
 [-FilePath <string>] [-StorageAccountKey <string>] [-SasToken <string>] [-Source <string>]
 [-Metadata <string[]>] [-ContentType <string>] [-ContentEncoding <string>]
 [-ContentLanguage <string>] [-ContentDisposition <string>] [-CacheControl <string>]
 [-Timeout <int>] [-ClientRequestId <string>] [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Uploads a local file to a path in a file share. The cmdlet creates the file at the size of the source and then writes its content in ranges. The parent directory must already exist. Authenticate with -StorageAccountName and -StorageAccountKey, or with -SasToken. Alternatively, pass the full resource URL with -Url.

## EXAMPLES

### Example 1: Upload a file

```powershell
Set-AzStorageFileContent -StorageAccountName mystorageaccount -StorageAccountKey $env:AZURE_STORAGE_KEY -ShareName myshare -FilePath mydir/myfile.txt -Source ./myfile.txt
```
