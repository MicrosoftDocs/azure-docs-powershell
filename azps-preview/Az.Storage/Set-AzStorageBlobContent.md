# Set-AzStorageBlobContent

## SYNOPSIS

Uploads a local file as a block blob.

## SYNTAX

### Default (Default)

```
Set-AzStorageBlobContent -FilePath <string> [-Url <string>] [-StorageAccountName <string>]
 [-StorageAccountKey <string>] [-SasToken <string>] [-ContainerName <string>] [-BlobName <string>]
 [-Metadata <string[]>] [-Tags <string[]>] [-BlobContentType <string>]
 [-BlobContentEncoding <string>] [-BlobContentLanguage <string>] [-BlobContentDisposition <string>]
 [-BlobCacheControl <string>] [-Tier <string>] [-EncryptionScope <string>] [-Timeout <int>]
 [-ClientRequestId <string>] [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Uploads a local file to a container as a block blob. An existing blob with the same name is not overwritten. Set content headers, metadata, tags and the access tier on the new blob. Authenticate with -StorageAccountName and -StorageAccountKey, or with -SasToken. Alternatively, pass the full resource URL with -Url.

## EXAMPLES

### Example 1: Upload a file

```powershell
Set-AzStorageBlobContent -StorageAccountName mystorageaccount -StorageAccountKey $env:AZURE_STORAGE_KEY -ContainerName mycontainer -BlobName myblob.txt -FilePath ./myfile.txt
```

### Example 2: Upload a file with a content type and metadata

```powershell
Set-AzStorageBlobContent -StorageAccountName mystorageaccount -StorageAccountKey $env:AZURE_STORAGE_KEY -ContainerName mycontainer -BlobName report.json -FilePath ./report.json -BlobContentType application/json -Metadata 'team=storage', 'env=test'
```
