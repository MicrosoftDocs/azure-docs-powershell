# Get-AzStorageDirectory

## SYNOPSIS

Gets the properties of a directory.

## SYNTAX

### Default (Default)

```
Get-AzStorageDirectory [-Url <string>] [-StorageAccountName <string>] [-ShareName <string>]
 [-DirectoryPath <string>] [-StorageAccountKey <string>] [-SasToken <string>] [-Snapshot <string>]
 [-Timeout <int>] [-ClientRequestId <string>] [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Gets the properties and metadata of a directory in a file share. To list the content of a directory, use Get-AzStorageFile. Authenticate with -StorageAccountName and -StorageAccountKey, or with -SasToken. Alternatively, pass the full resource URL with -Url.

## EXAMPLES

### Example 1: Get a directory

```powershell
Get-AzStorageDirectory -StorageAccountName mystorageaccount -StorageAccountKey $env:AZURE_STORAGE_KEY -ShareName myshare -DirectoryPath mydir
```
