# Remove-AzStorageContainer

## SYNOPSIS

Deletes a blob container.

## SYNTAX

### Default (Default)

```
Remove-AzStorageContainer [-Url <string>] [-StorageAccountName <string>]
 [-StorageAccountKey <string>] [-SasToken <string>] [-ContainerName <string>] [-LeaseId <string>]
 [-IfModifiedSince <string>] [-IfUnmodifiedSince <string>] [-Timeout <int>]
 [-ClientRequestId <string>] [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Marks a container and all blobs in it for deletion. The container is removed later by garbage collection, and a container with the same name can't be created until then. Authenticate with -StorageAccountName and -StorageAccountKey, or with -SasToken. Alternatively, pass the full resource URL with -Url.

## EXAMPLES

### Example 1: Delete a container

```powershell
Remove-AzStorageContainer -StorageAccountName mystorageaccount -StorageAccountKey $env:AZURE_STORAGE_KEY -ContainerName mycontainer
```
