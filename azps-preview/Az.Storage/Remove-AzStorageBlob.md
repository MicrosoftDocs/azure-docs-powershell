# Remove-AzStorageBlob

## SYNOPSIS

Deletes a blob.

## SYNTAX

### Default (Default)

```
Remove-AzStorageBlob [-Url <string>] [-StorageAccountName <string>] [-StorageAccountKey <string>]
 [-SasToken <string>] [-ContainerName <string>] [-BlobName <string>] [-DeleteSnapshots <string>]
 [-Snapshot <string>] [-VersionId <string>] [-BlobDeleteType <string>] [-LeaseId <string>]
 [-IfModifiedSince <string>] [-IfUnmodifiedSince <string>] [-IfMatch <string>]
 [-IfNoneMatch <string>] [-IfTags <string>] [-Timeout <int>] [-ClientRequestId <string>]
 [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Deletes a blob. If the blob has snapshots, set -DeleteSnapshots to include to delete the blob with its snapshots, or to only to delete just the snapshots. Authenticate with -StorageAccountName and -StorageAccountKey, or with -SasToken. Alternatively, pass the full resource URL with -Url.

## EXAMPLES

### Example 1: Delete a blob

```powershell
Remove-AzStorageBlob -StorageAccountName mystorageaccount -StorageAccountKey $env:AZURE_STORAGE_KEY -ContainerName mycontainer -BlobName myblob.txt
```

### Example 2: Delete a blob and its snapshots

```powershell
Remove-AzStorageBlob -StorageAccountName mystorageaccount -StorageAccountKey $env:AZURE_STORAGE_KEY -ContainerName mycontainer -BlobName myblob.txt -DeleteSnapshots include
```
