# Get-AzStorageBlobContent

## SYNOPSIS

Downloads a blob to a local file.

## SYNTAX

### Default (Default)

```
Get-AzStorageBlobContent -FilePath <string> [-Url <string>] [-StorageAccountName <string>]
 [-StorageAccountKey <string>] [-SasToken <string>] [-ContainerName <string>] [-BlobName <string>]
 [-Snapshot <string>] [-VersionId <string>] [-LeaseId <string>] [-EncryptionKey <string>]
 [-EncryptionKeySha256 <string>] [-EncryptionAlgorithm <string>] [-IfModifiedSince <string>]
 [-IfUnmodifiedSince <string>] [-IfMatch <string>] [-IfNoneMatch <string>] [-IfTags <string>]
 [-Timeout <int>] [-ClientRequestId <string>] [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Downloads the content of a blob to a local file. Use -Snapshot or -VersionId to download a specific snapshot or version. Authenticate with -StorageAccountName and -StorageAccountKey, or with -SasToken. Alternatively, pass the full resource URL with -Url.

## EXAMPLES

### Example 1: Download a blob

```powershell
Get-AzStorageBlobContent -StorageAccountName mystorageaccount -StorageAccountKey $env:AZURE_STORAGE_KEY -ContainerName mycontainer -BlobName myblob.txt -FilePath ./downloaded.txt
```
