# Remove-AzStorageDirectory

## SYNOPSIS

Deletes an empty directory.

## SYNTAX

### Default (Default)

```
Remove-AzStorageDirectory [-Url <string>] [-StorageAccountName <string>] [-ShareName <string>]
 [-DirectoryPath <string>] [-StorageAccountKey <string>] [-SasToken <string>] [-Timeout <int>]
 [-ClientRequestId <string>] [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Deletes a directory from a file share. The directory must be empty. Authenticate with -StorageAccountName and -StorageAccountKey, or with -SasToken. Alternatively, pass the full resource URL with -Url.

## EXAMPLES

### Example 1: Delete a directory

```powershell
Remove-AzStorageDirectory -StorageAccountName mystorageaccount -StorageAccountKey $env:AZURE_STORAGE_KEY -ShareName myshare -DirectoryPath mydir
```
