# New-AzStorageFile

## SYNOPSIS

Creates an empty file in a file share.

## SYNTAX

### Default (Default)

```
New-AzStorageFile [-Url <string>] [-StorageAccountName <string>] [-ShareName <string>]
 [-FilePath <string>] [-StorageAccountKey <string>] [-SasToken <string>] [-Size <long>]
 [-Metadata <string[]>] [-ContentType <string>] [-ContentEncoding <string>]
 [-ContentLanguage <string>] [-ContentDisposition <string>] [-CacheControl <string>]
 [-Timeout <int>] [-ClientRequestId <string>] [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Creates a file in a file share without uploading content. Use -Size to set the file length in bytes; the content is zero-filled. Use Set-AzStorageFileContent to upload a local file instead. Authenticate with -StorageAccountName and -StorageAccountKey, or with -SasToken. Alternatively, pass the full resource URL with -Url.

## EXAMPLES

### Example 1: Create an empty file

```powershell
New-AzStorageFile -StorageAccountName mystorageaccount -StorageAccountKey $env:AZURE_STORAGE_KEY -ShareName myshare -FilePath mydir/empty.txt
```

### Example 2: Create a 1 KiB file

```powershell
New-AzStorageFile -StorageAccountName mystorageaccount -StorageAccountKey $env:AZURE_STORAGE_KEY -ShareName myshare -FilePath mydir/sized.bin -Size 1024
```
