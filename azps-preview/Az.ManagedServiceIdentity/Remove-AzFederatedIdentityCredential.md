# Remove-AzFederatedIdentityCredential

## SYNOPSIS

Removes a federated identity credential from a user-assigned managed identity.

## SYNTAX

### Default (Default)

```
Remove-AzFederatedIdentityCredential -ResourceGroupName <string> -IdentityName <string>
 -Name <string> [-SubscriptionId <string>] [-Profile <string>] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## ALIASES

This cmdlet has no aliases.


## DESCRIPTION

Permanently deletes a federated identity credential from a user-assigned managed identity. This action cannot be undone.

## EXAMPLES

### Example 1: Remove a federated credential

Remove a federated identity credential from a user-assigned managed identity.

```powershell
Remove-AzFederatedIdentityCredential -ResourceGroupName myResourceGroup -IdentityName myIdentity -Name myFederatedCredential
```
