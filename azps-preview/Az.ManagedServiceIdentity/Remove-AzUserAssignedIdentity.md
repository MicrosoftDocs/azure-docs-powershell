# Remove-AzUserAssignedIdentity

## SYNOPSIS

Removes a user-assigned managed identity.

## SYNTAX

### __AllParameterSets

```
Remove-AzUserAssignedIdentity -ResourceGroupName <string> -Name <string> [-SubscriptionId <string>]
 [-Profile <string>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

This cmdlet has no aliases.


## DESCRIPTION

Removes a user-assigned managed identity from a resource group.

## EXAMPLES

### Example 1: Remove a user-assigned managed identity

Remove a user-assigned managed identity from a resource group.

```powershell
Remove-AzUserAssignedIdentity -ResourceGroupName myResourceGroup -Name myIdentity
```
