# Troubleshoot Azure PowerShell issues (preview)

This article explains how to report issues with the Azure PowerShell preview.

## Report an issue

If you encounter a problem that you can't resolve, report it in [the AzCLIPS GitHub repository][01].

Include:

- A description of the issue
- The command you ran
- Any relevant error messages or output
- Your operating system and PowerShell version
- The Azure PowerShell preview module version
- Steps to reproduce the issue
- Expected and actual behavior

Before sharing commands, logs, or output, remove credentials, access tokens, and sensitive information.
